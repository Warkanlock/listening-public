# Reporting a vulnerability

Use the repository’s **Security → Advisories → Report a vulnerability** form when it is available. If the form is unavailable, ask the maintainer for a private reporting channel. Use a public issue only to request that channel and leave out vulnerability details.

Include the version, affected feature, observed impact, and the smallest example that demonstrates the issue. Leave out active credentials, device invitations, private addresses, and personal music or account data.

Listening is designed to run on an operator’s trusted network. See the [private installation guide](docs/private-install.md#choose-how-devices-reach-the-room) for bind addresses and private HTTPS.
